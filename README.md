# Portfólio | Ana Julia Barbaresco Viana

Site pessoal que apresenta minha trajetória acadêmica, projetos, participação em feiras e habilidades. Ele complementa meu currículo e foi feito como trabalho do curso Técnico em Informática integrado ao Ensino Médio, no IFMS (campus Nova Andradina).

🔗 **Site publicado:** https://anajuliabvv.github.io/Portfolio/

## Seções do site

- **Sobre mim:** apresentação, curso e instituição
- **Atividades acadêmicas:** cursos, monitoria e grêmio estudantil
- **Projetos:** trabalhos desenvolvidos, com descrição e link para o código
- **Feiras e eventos:** FeciNova, com premiação de 1º lugar na categoria CHSAL
- **Habilidades:** tecnologias e idiomas
- **Contato:** e-mails e GitHub

## Tecnologias utilizadas

- **HTML5**, para a estrutura das páginas
- **CSS3**, para o visual, o layout responsivo (Grid e Flexbox) e as animações
- **JavaScript**, para o menu no celular e para abrir as fotos em tamanho grande
- **Git e GitHub**, para versionamento do código
- **GitHub Pages**, para a hospedagem

## Funcionalidades

- Animação de entrada: os componentes sobem quando a página abre
- Fotos que levantam ao passar o mouse e abrem ampliadas ao clicar
- Menu de navegação com rolagem suave
- Layout responsivo, que funciona em celular, tablet e computador

## Como executar localmente

1. Clone o repositório:
   ```
   git clone https://github.com/anajuliabvv/Portfolio.git
   ```
2. Entre na pasta:
   ```
   cd Portfolio
   ```
3. Abra o arquivo `index.html` no navegador (dois cliques nele).
