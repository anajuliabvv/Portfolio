# Portfólio | Ana Julia Barbaresco Viana

Site pessoal feito com HTML, CSS e JavaScript, hospedado no GitHub Pages.

## Como publicar
1. Crie um repositório no GitHub (ex.: `portfolio`) e envie todos os arquivos desta pasta.
2. Em Settings > Pages, escolha Branch `main` / pasta `/ (root)` e salve.
3. O site ficará em `https://SEU-USUARIO.github.io/portfolio/`.
